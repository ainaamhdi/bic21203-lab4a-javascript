### Project Description
This project consists of three JavaScript exercises that demonstrate the use of JavaScript functions, event handling, conditional statements, loops and DOM manipulation.

### Question 1 – Interactive Text Changer
This webpage changes the paragraph text from "Welcome to my website!" to "Hello there!" when the user clicks the button.

**How to run:**
1. Open the Q1 folder.
2. Open index.html in a web browser.
3. Click the Change Message button.

### Question 2 – Smart Number Validator
This webpage accepts a number from the user and displays a validation message based on the entered value.

**How to run:**
1. Open the Q2 folder.
2. Open index.html in a web browser.
3. Enter a number and click Check.

### Question 3 – Dynamic Number Generator
This webpage generates an ordered list containing numbers from 1 to 5 when the user clicks the Generate button.

**How to run:**
1. Open the Q3 folder.
2. Open index.html in a web browser.
3. Click the Generate button.
